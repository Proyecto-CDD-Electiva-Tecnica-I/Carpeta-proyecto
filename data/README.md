# Fuentes de datos del proyecto

Aquí se registran los enlaces oficiales de los conjuntos de datos utilizados:

1. **MEN - Matrícula Estadística Educación Superior (390.903 filas aprox.):**
   - Enlace: https://www.datos.gov.co/Educaci-n/MEN_MATRICULA_ESTADISTICA_ES/5wck-szir/about_data
   - Descripción: Características académicas y matrícula.

2. **SNIES - Bases consolidadas (2015–2025):**
   - Enlace: https://snies.mineducacion.gov.co/portal/ESTADISTICAS/Bases-consolidadas/
   - Descripción: Datos estadísticos desde admitidos hasta graduados.

3. **SPADIES - Estadísticas de deserción (2010–2024):**
   - Enlace: https://www.mineducacion.gov.co/sistemasinfo/spadies/secciones/Estadisticas-de-desercion/
   - Descripción: Estadísticas de deserción.
